### NDC(Normalized Device Coordinates)란?
NDC는 [[원근 나눗셈]]을 통해 [[Clip Space]] 좌표를 정규화한 좌표계이다.

NDC는 화면 해상도와 독립적인 정규화 좌표를 사용하며, 이후 Viewport Transform을 통해 실제 화면영역에 대응되는 좌표로 변환된다.

###### NCD의 좌표범위

| 축   | 일반적인 범위                      |
| --- | --------------------------- |
| X   | -1 ~                         |
| Y   | -1                           |
| Z 그래픽 API에 따라 0 ~ 1 or -1 ~ 1  or  |
이때, 일반적으로 X, Y좌표는 화면 중심을 (0, 0)으로 표현한다.

### 내부 동작 원리
1. [[Clipping]]을 거친 정점의 [[동차 좌표]]를 전달받는다.
2. X,Y,Z를 W로 나누어 NDC를 계산한다.
3. 투영된 가시영역의 좌표가 정해진 NDC 범위에 대응하도록 표현된다.
4. NDC의 X,Y좌표를 실제 화면영역의 좌표로 변환한다.
5. 변환된 좌표를 기준으로 래스터화와 프래그먼트 처리를 한다.


###### NCD에서 화면 좌표로 변환
화면 크기가 1920×1080일 경우, 화면 전체를 뷰포트로 사용한다면 NDC의 X, Y 좌표는 다음과 같이 변환할 수 있다.
$$ X_{screen}=\frac{X_{NDC}+1}{2}\times1920\\ 
 Y_{screen}=\frac{Y_{NDC}+1}{2}\times1080 $$


### 특징과 제약

| 특징                          | 제약                              |
| --------------------------- | ------------------------------- |
| 화면 해상도와 독립적인 좌표 표현          | 실제 픽셀 좌표가 아니므로 추가 변환 필요         |
| X,Y를 -1 ~ 1로 정규화            | 그래픽 API에 따라 Z좌표 규칙 차이           |
| Viewport Transform의 입력으로 활용 | 원근 투영 시 깊이값이 일반적인 거리와 선형 관계가 아님 |
