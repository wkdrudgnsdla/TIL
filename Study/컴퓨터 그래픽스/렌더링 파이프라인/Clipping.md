### Clipping(클리핑)이란?
Clipping이란 카메라의 가시영역을 벗어나는 도형의 일부 혹은 전체를 잘라내는 렌더링 과정이다.

GPU는 [[Vertex Shader]]에서 변환된 정점의 [[Clip Space]]좌표를 이용해 도형이 가시 영역 내에 존재하는지를 판단한다.

도형이 가시영역에 일부만 걸쳐있다면, 보이는 부분만 남기도록 새로운 정점을 생성하여 도형을 재구성할 수 있다.
![[Pasted image 20261013193722.png]]


### 내부 동작원리
1. Vertex Shader에서 변환된 Clip Space 좌표를 전달받는다.
2. 각 도형의 정점이 클리핑 경계의 내부 또는 외부에 있는지 확인한다.
3. 도형이 결계에 걸쳐있다면 교차첨을 계산하고 정점을 생성한다.
4. 가시영역 내부에 남은 부분으로 도형을 재구성한다.
5. 남은 도형에 원근 나눗셈과 레스터화 등의 처리를 한다.




### [[Frustum Culling]]과의 차이

| 구분         | Frustum Culling      | Clipping            |
| ---------- | -------------------- | ------------------- |
| 처리 단위      | 주로 오브젝트의 Bounds      | 삼각형등 기본 도형          |
| 주요 목적      | 보이지 않는 오브젝트 제외       | 가시영역 밖의 도형 절단       |
| 처리 위치      | 보통 렌더링 명령 제출 전       | GPU 렌더링 파이프라인       |
| 일부만 보이는 도형 | 오브젝트를 렌더링 대상으로 유지 가능 | 경계를 기준으로 보이는 부분만 남김 |




### 특징과 제약

| 특징                 | 제약                                             |
| ------------------ | --------------------------------------------- |
| 가시영역 밖의 도형 제거 가능   | 경계에 걸친 도형의 절단 연산비용                             |
| 일부만 보이는 도형도 렌더링 가능 | 가려진 오브젝트를 모두 제거하는 기능은                      님   |
| 불필요한 후속 레스터화 감소  Vertex Shader 처리 이후 수행되므로 이전 단계의 연산까지 제거하지 못함 되므로  |
