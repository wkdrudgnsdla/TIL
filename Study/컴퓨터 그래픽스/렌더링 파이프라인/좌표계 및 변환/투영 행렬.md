### Projection Matrix(투영 행렬)이란?
투영행렬은 카메라의 View Space 좌표를 [[Clip Space]]좌표로 변환하는 4 * 4행렬이다.

카메라의 시야각(FOV), 화면 종횡비(Aspect Ratio), Near/Far Clip Plane 등을 기반으로 구성되며,
물체가 화면에 어떻게 투영될지를 결정한다.


대표적인 투영방식에는 원근투영(Perspective Projection)과 직교투영(Orthographic Projection)이 있다.

| 구분           | 원근투영       | 직교투영           |
| ------------ | ---------- | -------------- |
| **거리별 크기변화** | 있음         | 없음             |
| **원근감**      | 표현가능       | 표현하지 않음        |
| **대표적인 사용**  | 3D 게임 카메라  | 2D 게임, 등각 투영게임 |
| **일반적인 W값**  | 깊이에 따라 달라짐 | 보통 1로 유지       |



### 내부 동작 원리
1. FOV, Aspect Ratio, Near/Far Plane 등의 값을 확인한다.
2. 카메라 설정과 투영 방식에 따라 4×4 행렬을 구성한다.
3. View Space의 정점 좌표를 입력받는다.
4. 투영 행렬과 정점 좌표를 곱하여 Clip Space로 변환한다.
5. 계산된 클립 좌표를 이후 [[Clipping]] 및 [[원근 나눗셈]] 과정에 사용한다.

###### 투영 행렬의 연산
$$ P_{clip}=M_{projection}\times P_{view} $$
- $P_{view}$: View Space의 정점 좌표
- $M_{projection}$: 투영 행렬
- $P_{clip}$: 변환된 Clip Space 좌표
이때, 투영 행렬의 결과는 아직 [[NDC]]가 아니다.
투영 행렬을 적용하면 Clip Space의 좌표가 만들어지고, 이후 원근 나눗셈을 통해 NDC로 변환된다.

### 특징과 제약

| 특징                         | 제약                               |
| -------------------------- | -------------------------------- |
| 카메라의 투영 방식을 행렬로 표현         | 투영 방식에 따라 결과가 달라짐                |
| View Space를 Clip Space로 변환 | 투영 행렬만으로 최종 화면 픽셀 좌표를 얻을 수 없음    |
| FOV, Aspect Ratio 등을 반영    | 잘못된 Near/Far 설정은 깊이 정밀도 문제 유발 가능 |
| 원근 투영과 직교 투영 지원            | 그래픽 API에 따라 행렬 보정 필요 가능          |
