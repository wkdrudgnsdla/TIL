### Homogeneous Coordinates (동차 좌표)란?
동차좌표는 일반적인 x, y, z축으로 이루어진 3차원 좌표에 w성분을 추가하여 (x, y, z, w)의 형태로 표현하는 좌표 체계이다.

일반적인 3D좌표에서는 위치, 회전, 크기 변환뿐 아니라 이동을 하나의 3 * 3 행렬만으로 표현할 수  없다.
하지만, 동차좌표의 4 * 4 행렬을 사용하면 위치, 회전, 크기변환 및 원근투영등을 행렬곱셈으로 통합하여
표현할 수 있다.




###### 동차 좌표의 구성

| 좌표  | 역할                               |
| --- | -------------------------------- |
| X   | X축 좌표성분                          |
| Y   | Y축 좌표성분                          |
| Z   | Z축 좌표성분                          |
| W   | 동차 좌표의 스케일 및 [[원근 나눗셈]]에 사용되는 성분 |

일반적으로 3D 좌표를 동차 좌표로 구현할 때 아래와 같이 구분한다.
```
위치(Point) : (x, y, z, 1)
방향(Vector): (x, y, z, 0)
```
방향 벡터에서 W가 0이면 일반적인 변환 행렬의 이동 성분에 영향을 받지 않는다.
반면 위치는 W가 1이므로 이동 변환의 영향을 받는다.


### 내부 동작원리
1. 3차원 좌표에 W성분을 추가하여 4차원 형태로 표현한다.
2. 4 * 4 변환 행렬을 곱하여 위치, 회전, 크기등의 변환을 수행한다.
3. 필요에 따라 [[투영 행렬]]을 적용하여 [[Clip Space]]좌표로 변환한다.
4. W가 0이 아닌 좌표는 필요할 때 X, Y, Z를 W로 나누어 일반적인 3차원 좌표로 변환한다.

ex)
```
A = (2, 4, 6, 2)
B = (1, 2, 3, 1)
```
위의 A와 B 두 등차 좌표를 보았을 때, 각 좌표를 모두 W로 나누면 두 좌표 모두 (1, 2, 3)이 된다.
따라서, 두 등차좌표는 동일한 3차원 위치를 나타낸다.

하지만 W가 0인 방향벡터에는  일반적인 원근 나눗셈을 적용하지 않는다.



### 특징과 제약

| 특징                       | 제약                      |
| ------------------------ | ----------------------- |
| 이동, 크기, 회전 변환을 행렬로 변환 가능 | 기존 3차원 좌표보다 성분이 하나 더 많음 |
| 원근 투영을 행렬 연산으로 표현 가능     | W값의 의미와 활용 방식에 대한 이해 필요 |
| 위치와 방향벡터를 구분가능           | W가 0일때 일반적인 원근 나눗셈 불가   |
